# Pokemon-Trade-Thumbnail-Maker

ポケモン交換会のサムネイルを作成するWebアプリです。使い方次第では通常のサムネイルも直感的な操作で作成できます。

## 概要

このアプリは、ポケモン交換会や配信イベント用のサムネイルを簡単に作成できるツールです。背景画像やロゴ、ポケモンの画像を自由に配置し、タイトルや枠線のカスタマイズも可能です。直感的な操作で、オリジナルのサムネイルを作成できます。

## 主な機能

- 背景画像の選択
- ロゴの追加・配置
- ポケモンやボール、アイコンの追加・配置
- タイトル文字の編集（フォント、サイズ、色、縁取りの設定）
- 外枠のカスタマイズ（色、太さ、グラデーション対応）
- ZIPファイルやJSON設定ファイルの読み込み・保存
- 作成したサムネイル画像の保存

## 使い方

1. **ファイルの読み込み**
   - 画面左側の「📂 設定読込 (.json)」ボタンをクリックして、設定ファイルを読み込むか、ZIPファイルをドラッグ＆ドロップしてください。※ZIPファイルを先に読み込ませてください。
   - ZIPファイルには、背景画像やポケモン画像などを含めてください。

2. **設定の編集**
   - **外枠・背景タブ**: 背景画像や外枠の設定を行います。
   - **ロゴタブ**: ロゴを追加し、位置やサイズを調整します。
   - **タイトルタブ**: タイトル文字の内容やフォント、色、縁取りを設定します。位置の調整も行えます。
   - **ポケモン設定タブ**: ポケモンやボール、アイコンを追加し、位置やサイズを調整します。

3. **プレビュー**
   - 右側のプレビューエリアで、設定内容をリアルタイムに確認できます。

4. **サムネイルの保存**
   - 「画像を保存」ボタンをクリックして、作成したサムネイルをPNG形式で保存します。

5. **設定の保存**
   - 「⚙️ 設定保存 (config.json)」ボタンをクリックして、現在の設定をJSONファイルとして保存できます。

## 必要なファイル構成

- 背景画像: `back/` フォルダ内
- ロゴ画像: `logo/` フォルダ内
- ポケモン画像: `pokemon/` フォルダ内
- ボール画像: `ball/` フォルダ内
- その他アイコン: `etc/` フォルダ内

```text
images.zip
 ┣ back/
 ┃   ┗ bg_image1.png     (背景用画像)
 ┣ logo/
 ┃   ┗ logo_title.png    (ロゴ用画像)
 ┣ pokemon/
 ┃   ┗ pikachu.png       (ポケモン用画像や立ち絵などのイラスト)
 ┣ ball/
 ┃   ┗ monster_ball.png  (ボール用画像)
 ┗ etc/
     ┗ shiny_mark.png    (その他アイコン用画像)
```

## 開発者向け情報

- ZIPファイルの解凍には [JSZip](https://stuk.github.io/jszip/) ライブラリを使用しています。
