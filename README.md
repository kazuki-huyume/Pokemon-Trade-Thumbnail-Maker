# Pokemon-Trade-Thumbnail-Maker

ポケモン交換会のサムネイルを作成するWebアプリです。使い方次第では通常のサムネイルも直感的な操作で作成できます。

https://kazuki-huyume.github.io/Pokemon-Trade-Thumbnail-Maker/

## 概要

このアプリは、ポケモン交換会や配信イベント用のサムネイルを簡単に作成できるツールです。背景画像やロゴ、ポケモンの画像を自由に配置し、タイトルや枠線のカスタマイズも可能です。直感的な操作で、オリジナルのサムネイルを作成できます。

## 主な機能

- 背景画像の選択
- ロゴの追加・配置（複数対応）
- ポケモンやボール、アイコンの追加・配置（複数対応）
- 配信タイトルの複数追加・配置（フォント、サイズ、単色・グラデーション、一重・二重縁取りをオブジェクトごとに個別設定可能）
- 外枠のカスタマイズ（色、太さ、グラデーション対応）
- `font/` フォルダ内のカスタムフォントファイル（`.ttf` / `.otf` 等）の動的読み込み
- ZIPファイルやJSON設定ファイルの読み込み・保存
- 作成したサムネイル画像の保存

## 使い方

1. **ファイルの読み込み**
   - 画面左側の「📂 設定読込 (.json)」ボタンをクリックして、設定ファイルを読み込むか、ZIPファイルをドラッグ＆ドロップしてください。
   - ZIPファイルには、背景画像やカスタムフォント、ポケモン画像などを含めてください。

2. **設定の編集**
   - **外枠・背景タブ**: 背景画像や外枠の設定を行います。
   - **ロゴタブ**: ロゴを追加し、位置やサイズを調整します。
   - **タイトルタブ**: 複数のタイトルを追加・編集し、フォントや色、縁取り、グラデーションを設定します。
   - **ポケモン設定タブ**: ポケモンやボール、アイコンを追加し、位置やサイズを調整します。

3. **プレビュー**
   - 右側のプレビューエリアで、設定内容をリアルタイムに確認できます（オブジェクトはキャンバス上で直接ドラッグして位置調整が可能です）。

4. **サムネイルの保存**
   - 「画像を保存」ボタンをクリックして、作成したサムネイルをPNG形式で保存します。

5. **設定の保存**
   - 「⚙️ 設定保存 (config.json)」ボタンをクリックして、現在の設定をJSONファイルとして保存できます。

## 必要なファイル構成とZIPファイルの仕様

アプリに読み込ませるZIPファイルは、以下のフォルダ階層（カテゴリ別のフォルダ分け）でファイルを格納している必要があります。ZIPファイルを解凍した際に、各フォルダ内のファイルが自動的に分類されます。

```text
images.zip
 ┣ back/
 ┃   ┗ bg_image1.png     (背景用画像)
 ┣ logo/
 ┃   ┗ logo_title.png    (ロゴ用画像)
 ┣ pokemon/
 ┃   ┗ pikachu.png       (ポケモン用画像)
 ┣ ball/
 ┃   ┗ monster_ball.png  (ボール用画像)
 ┣ etc/
     ┗ shiny_mark.png    (その他アイコン用画像)
 ┗ font/
     ┗ M_PLUS_Rounded_1c.ttf (カスタムフォントファイル)
```

back/: 配信の背景となる画像ファイルを格納します。

logo/: チャンネルロゴやイベントロゴなどの画像を格納します。

pokemon/: ポケモンの立ち絵や画像などを格納します。

ball/: ポケモンボールのアイコン画像を格納します。

etc/: その他装飾用や持ち物などのアイコン画像を格納します。

font/: サブタイトルやタイトルに使用したいカスタムフォントファイル（.ttf, .otf, .woff, .woff2 等）を格納します。ここに配置したフォントは、自動的にアプリ内のフォント選択プルダウンに追加されます。
